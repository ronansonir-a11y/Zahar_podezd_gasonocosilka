# Захар: Вечная лестница

3D-хоррор-аркада про Захара, который на газонокосилке катится по **бесконечной лестнице обычной российской пятиэтажки**. Ступени, площадки, перила, двери, номера этажей и мигающая лампочка повторяются снова и снова: `1 → 2 → 3 → 4 → 5 → снова 1`. Сосед со второго фото стоит на площадке, бросает вёдра и иногда появляется прямо перед экраном. Нужно уворачиваться, перепрыгивать препятствия, собирать монеты и канистры и косить траву ради очков.

**Готовый APK:** [`dist/ZaharPodiezdMower.apk`](dist/ZaharPodiezdMower.apk) — подписан локальным debug-ключом, схемы подписи v2 и v3 проверены. Минимальная версия Android 7.0 (API 24), target API 34. Имя приложения: «Захар: Вечная лестница».

## Управление

- `◀` / `▶` или `A` / `D`, либо свайп влево-вправо по левой части экрана — руль.
- `ГАЗ` / `W` / `↑` — ускорение, расходует бензин (медленно восстанавливается).
- `ПРЫЖОК` / `Space` — перепрыгнуть конус, ведро или покрышку.
- `❚❚` / `P` / `Esc` / системная кнопка «Назад» — пауза.
- `Enter` — старт / рестарт.

## Что нового в этой версии

- **Подъезд стал вечной лестницей.** Вместо коридора — летящие навстречу марши из 9 ступеней, площадки, перила, боковые стены, потолок, двери, таблички с номером этажа, лампочка и призрак соседа. Короткий туман скрывает стык между циклами.
- **Петля из пяти этажей.** Каждые 250 м номер этажа меняется `1 → 5 → 1`, каждый новый круг немного ускоряет игру. В HUD видны `ЭТАЖ` и `КРУГ`.
- **Хоррор-атмосфера:** почти чёрная палитра, мигающий свет, красные вспышки, скример с лицом соседа, низкий гул двигателя, шёпот, резкие звуковые «удары», туман и дешёвые CRT-полосы поверх картинки.
- **Сосед и Хозяин лестницы.** Обычный сосед появляется на площадке и бросает препятствия; каждые 500 м приходит «Хозяин лестницы» и 8 секунд швыряет сразу несколько предметов. За выживание `+500`.
- **Бонусы переименованы под хоррор:** иконка гасит столкновение, свеча притягивает монеты, `×2` удваивает очки на 9 секунд.
- **Графику намеренно ухудшили**, чтобы не лагало на слабом телефоне. Подробности ниже.

Есть 3 жизни, счёт, рекорд в `localStorage`, виброотдача и процедурный звук через WebAudio. Интернет и разрешения не нужны.

## Графика и производительность

Предыдущая «красивая» версия с PBR, тенями, свечением и авто-FPS **полностью убрана**. Теперь всё дешевле и намеренно грубее:

- Фиксированный **pixel ratio 0.75**, без `antialias`, без `tone mapping`, без `shadowMap`.
- Только **2 источника света**: `HemisphereLight` + один `DirectionalLight`. Нет точечных ламп, rim-light и fill-light.
- Только `MeshLambertMaterial` / `MeshBasicMaterial` с `flatShading`. Нет `MeshStandardMaterial`, PBR, metalness/roughness, normal maps, environment map и отражений.
- Все текстуры — `NearestFilter`, без mipmaps и анизотропии: сознательно пиксельный «плохой» вид и меньше работы GPU.
- Убраны мягкие тени, контактные тени от реального света, glow-спрайты, световые пятна, пыль и полноценный постпроцессинг. Вместо них — короткий туман, CSS-виньетка и CSS-полосы.
- Меньше геометрии и объектов: 7 повторяющихся лестничных сегментов, 14 препятствий, 12 подборов, 8 пятен травы и 50 частиц вместо прежних больших пулов.
- `powerPreference: 'low-power'`, короткий туман (`8–44`), WebView с hardware layer и запретом сетевых загрузок.
- Никаких SSAO, bloom, отражений в реальном времени, адаптивного качества и переключателей графики: один фиксированный дешёвый режим.

В HUD остался счётчик FPS и подпись `ПЛОХО · 75%`, чтобы было видно, что режим выбран специально.

## Что внутри

- `app/index.html`, `app/style.css`, `app/game.js` — игра на WebGL/Three.js.
- `app/vendor/three.min.js` — Three.js r149 (MIT, лицензия рядом).
- `app/textures/` — 30 PNG-текстур: пол, стены, потолок, кирпич, двери, почтовые ящики, плакаты, трава, газонокосилка, монеты, канистра, портреты и вырезанные персонажи.
- `source_art/` — исходные AI-портреты/фигуры, из которых `tools/make_textures.py` делает прозрачные спрайты.
- `android/` — минимальная Java-обёртка `WebView`, манифест, строки и иконки launcher.
- `tools/make_textures.py` — генерация текстур и иконок из `source_art/`.
- `tools/setup_tools.py` — кэширует инструменты сборки в `~/.cache/zahar-apk-tools`.
- `tools/build_apk.py` — полный цикл `aapt2 → ECJ → DX → APK → apksigner → verify`.

## Сборка из исходников

```bash
python3 tools/build_apk.py
```

Первый запуск скачает с `registry.npmjs.org`, `pypi.org` и `github.com` кешируемый набор: `aapt2`, ECJ, Android 34 `android.jar`, DX из AOSP, `apksigner`, JRE и Three.js. Android Studio / Gradle / Android SDK не нужны. Пересборка текстур:

```bash
python3 tools/make_textures.py
```

## Установка

```bash
adb install -r dist/ZaharPodiezdMower.apk
```

APK собран с самоподписанным debug-сертификатом. Для публикации в магазине замените `build/apk/debug.p12` на свой release-ключ и пересоберите. Если WebView на устройстве очень старый и не поддерживает WebGL, игра покажет понятное сообщение вместо чёрного экрана.

## Предпросмотр в браузере

Из папки `app/` можно поднять статический сервер:

```bash
cd app && python3 -m http.server 8000 --bind 0.0.0.0
```

В текущей сессии он запущен на порту `8000`.

- APK пересобран, подпись v2/v3 проверена, внутри лежат обновлённые HTML/CSS/JS, `classes.dex` и 30 текстур.
- На физическом Android-устройстве FPS не замерялся; режим рассчитан на слабое железо.
