# Захар: Косилка в подъезде

3D-аркада про Захара, который катается по подъезду на газонокосилке, а сосед со второго фото бегает вперёд и расставляет конусы, вёдра, покрышки и мусорные баки. Нужно уворачиваться, перепрыгивать низкие препятствия, собирать монеты и канистры с бензином и косить траву ради очков.

**Готовый APK:** [`dist/ZaharPodiezdMower.apk`](dist/ZaharPodiezdMower.apk) — подписан локальным debug-ключом, схемы подписи v2 и v3 проверены. Минимальная версия Android 7.0 (API 24), target API 34.

## Управление

- `◀` / `▶` или `A` / `D`, либо свайп влево-вправо по левой части экрана — руль.
- `ГАЗ` / `W` / `↑` — ускорение, расходует бензин (медленно восстанавливается).
- `ПРЫЖОК` / `Space` — перепрыгнуть конус, ведро или покрышку.
- `❚❚` / `P` / `Esc` / системная кнопка «Назад» — пауза.
- `Enter` — старт / рестарт.

## Что нового в этой версии

- **Новый визуал и адаптивное качество:** PBR-материалы, мягкие тени, тёплый свет ламп, пыль, виньетка и переключатель `АВТО / МАКС / ЭКОНОМ` с авто-подстройкой под FPS.
- **Стены больше не «едут» боком.** Обои зафиксированы, движение коридора создают двери, лампы, почтовые ящики, плакаты и болларды.
- **Этажи.** Каждые 250 м коридор меняет оттенок, слегка ускоряется и даёт бонус `100 × номер этажа`. Номер этажа виден в HUD.
- **Три бонуса** вместо только монет и канистр:
  - **Щит** — гасит следующее столкновение без потери жизни;
  - **Магнит** — притягивает монеты к косилке;
  - **×2 очки** — удваивает очки за дистанцию на 9 секунд.
  Активные бонусы и их таймеры показываются слева внизу.
- **Старший по подъезду.** Каждые 500 м появляется огромный сосед с нимбом, который 8 секунд швыряет сразу несколько препятствий. За выживание начисляется `+500`. Во время босса обычный сосед и обычные волны не отвлекают.
- HUD с этажом, плашкой босса и таймерами бонусов; обновлено меню с подсказками.

Есть 3 жизни, бесконечный коридор, счёт, рекорд в `localStorage`, виброотдача, процедурный звук двигателя и звуки подборов/столкновений через WebAudio. Интернет и разрешения не нужны.

## Графика и производительность

- **PBR-материалы** (`MeshStandardMaterial`) на полу, стенах, косилке, металле и дверях; процедурные **normal maps** и компактный **environment map** дают блики и объём без тяжёлых HDR-ассетов.
- **Мягкие динамические тени**: один `DirectionalLight` с `PCFSoftShadowMap` 1024² (в «Экономе» 512²), камера тени следует за игроком, чтобы сохранить детализацию. Контактные тени-спрайты ослаблены, когда реальные тени включены.
- **Свет**: тёплый верхний свет, холодный заполняющий, задний rim-light, лёгкое мерцание ламп, аддитивное свечение вокруг светильников, световые пятна на полу и медленные пылинки в луках.
- **Цветокор**: ACES tone mapping, туман с оттенком текущего этажа и дешёвая CSS-виньетка вместо полноэкранного постпроцессинга.
- **Авто-качество**: старт с 115% pixel ratio, замер FPS каждую секунду; при просадках ниже 42 FPS разрешение падает до 85% и тени отключаются, при запасе выше 55 FPS качество плавно возвращается. В HUD виден счётчик FPS.
- **Ручной выбор** в меню: `АВТО` / `МАКС` / `ЭКОНОМ`. Выбор сохраняется в `localStorage`; «Эконом» отключает тени, свечение, световые пятна и пыль.
- **WebView** использует hardware layer и повышенный приоритет GPU-рендерера на Android 8+, сетевые загрузки запрещены.
- Сознательно нет SSAO, настоящего bloom, отражений в реальном времени и нескольких shadow-кастеров: визуальный эффект достигается дешёвыми приёмами, рассчитанными на среднебюджетный смартфон.

## Что внутри

- `app/index.html`, `app/style.css`, `app/game.js` — игра на WebGL/Three.js.
- `app/vendor/three.min.js` — Three.js r149 (MIT, лицензия рядом).
- `app/textures/` — 30 PNG-текстур: пол, стены, потолок, кирпич, двери, почтовые ящики, плакаты, трава, газонокосилка, монеты, канистра, портреты и вырезанные персонажи.
- `source_art/` — исходные AI-портреты/фигуры, из которых `tools/make_textures.py` делает прозрачные спрайты.
- `android/` — минимальная Java-обёртка `WebView`, манифест, строки и иконки launcher.
- `tools/make_textures.py` — генерация текстур и иконок из `source_art/`.
- `tools/setup_tools.py` — кэширует инструменты сборки в `~/.cache/zahar-apk-tools`.
- `tools/build_apk.py` — полный цикл `aapt2 → ECJ → DX → APK → apksigner → verify`.

## Сборка из исходников

```bash
python3 tools/build_apk.py
```

Первый запуск скачает с `registry.npmjs.org`, `pypi.org` и `github.com` кешируемый набор: `aapt2`, ECJ, Android 34 `android.jar`, DX из AOSP, `apksigner`, JRE и Three.js. Android Studio / Gradle / Android SDK не нужны. Пересборка текстур:

```bash
python3 tools/make_textures.py
```

## Установка

```bash
adb install -r dist/ZaharPodiezdMower.apk
```

APK собран с самоподписанным debug-сертификатом. Для публикации в магазине замените `build/apk/debug.p12` на свой release-ключ и пересоберите. Если WebView на устройстве очень старый и не поддерживает WebGL, игра покажет понятное сообщение вместо чёрного экрана.

## Предпросмотр в браузере

Из папки `app/` можно поднять статический сервер:

```bash
cd app && python3 -m http.server 8000 --bind 0.0.0.0
```

В текущей сессии он запущен на порту `8000`.
